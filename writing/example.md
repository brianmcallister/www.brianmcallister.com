This is a draft, so it shows up locally and in preview deployments but never on the live site. Copy it to start a new post, or delete it once there are real ones.

Paragraphs are separated by a blank line. Text can be **bold**, *italic* or `code`, and [links](https://www.brianmcallister.com/) work as usual.

## A section heading

Use `##` for sections, since the post's title is the page's main heading.

- Lists can be bulleted
- or numbered, by starting each line with `1.`, `2.` and so on
- and a long item can continue on an indented line
  like this one.

> Block quotes start with a greater-than sign.

```js
const code = 'Fenced blocks keep their formatting.';
```

---

Anything Markdown can't express can be written as HTML, as long as the block starts with a tag and has blank lines around it.
